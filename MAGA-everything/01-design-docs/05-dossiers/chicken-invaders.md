## Original mechanics (CI2/CI3 peak era)

1. Pilot ship; dodge egg projectiles; shoot chicken formations / bosses.
2. Collect gifts → cycle/upgrade weapons; drumsticks/roasts → missiles.
3. Clear waves per chapter → boss → next system (CI2: Pluto→Sun arc).
4. CI3+: overheat gun, modifiers, more weapons, local multiplayer.
5. Holiday editions reskin audio/art.
